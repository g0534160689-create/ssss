# KioskControl
תוכנת WPF ל-Windows 10/11 לניהול מקומי של רשימת תוכנות מורשות.

## דרישות
- Windows 10 או Windows 11
- .NET 8 SDK

## הרצה
מתיקיית KioskControl:
```powershell
dotnet restore
dotnet build
dotnet run
```

## יכולות בשלב הראשון
- ממשק ניהול בעברית
- הוספה של קובצי EXE
- הפעלה/השבתה של תוכנות ברשימה
- שמירת הגדרות ב-%ProgramData%\KioskControl\allowed-apps.json
- הפעלה מהירה של התוכנה שנבחרה

## מגבלת אבטחה חשובה
בשלב זה מדובר במנהל רשימה ומפעיל תוכנות בלבד. הוא אינו חוסם הפעלה של תוכנות אחרות דרך Explorer או מנגנוני Windows אחרים. אכיפה אמיתית תיבנה בנפרד באמצעות AppLocker או Windows Defender Application Control, בהתאם למהדורת Windows, תחילה במצב Audit ובחשבון בדיקה, עם אפשרות שחזור כדי למנוע נעילת מחשב.

## שלבי המשך
1. פרופילים, קטגוריות, חיפוש, יומן שינויים וייבוא/ייצוא.
2. מסך בית קיוסק במסך מלא.
3. שילוב מדיניות Windows לאכיפה אמיתית.
4. חשבון משתמש ייעודי, מצב יציאה למנהל ומנגנון שחזור.
5. מתקין, עדכונים והסרה מסודרת.
