# גרסאות להורדה

קובצי ההתקנה של Windows מתפרסמים בעמוד [GitHub Releases](https://github.com/g0534160689-create/ssss/releases).

## הורדת הגרסה האחרונה

1. פתחו את [עמוד Releases](https://github.com/g0534160689-create/ssss/releases).
2. בחרו את הגרסה העדכנית.
3. תחת **Assets** הורידו את `KioskControl-Setup.exe`.

## יצירת גרסה חדשה

תהליך הבנייה הקיים יוצר קובץ התקנה ומפרסם אותו אוטומטית ב-GitHub Releases כאשר נדחף תג (tag) בפורמט `v*`, לדוגמה `v0.1.0`.

הערה: קובצי EXE הם קבצים בינאריים, ולכן אינם נשמרים ישירות בתיקייה זו; הם מצורפים לכל גרסה בעמוד Releases.
